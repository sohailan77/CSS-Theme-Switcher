# 🎨 CSS Theme Switcher

A simple and responsive **CSS-only theme switcher** built with HTML5 and CSS3.  
It allows users to switch between Light, Dark, and Custom themes without JavaScript.

## ✨ Features

- ☀️ Light, Dark & Custom themes
- 🎯 CSS Custom Properties for theme management
- 🚫 No JavaScript required
- ♿ Keyboard-accessible theme controls
- 📱 Responsive design
- 🔍 Modern CSS `:has()` selector

## 🛠️ Built With

- 🌐 HTML5
- 🎨 CSS3
- 🔧 CSS Custom Properties
- 🔘 Radio Inputs
- 🔍 `:has()` Selector
